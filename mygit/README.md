# 🚗 Car-Sharing Daily Task Manager (카쉐어링 데일리 태스크)

카쉐어링 서비스 3대 핵심 도메인(**💬 채팅**, **👤 마이페이지**, **💳 결제수단**)의 일일 업무(10~20개)를 관리하는 풀스택 웹 애플리케이션입니다.

---

## 📁 파일 구성

| 파일명 | 구분 | 설명 |
| :--- | :--- | :--- |
| **`start.bat`** | **실행 파일** | **(더블 클릭)** 백엔드 서버를 구동하고 브라우저(`http://localhost:3000`)를 자동 실행 |
| **`stop.bat`** | **종료 파일** | **(더블 클릭)** 포트 3000에서 실행 중인 백엔드 서버를 즉시 종료 |
| **`start.ps1` / `stop.ps1`** | 실행/종료 | PowerShell 환경용 실행 및 종료 스크립트 |
| **`server.js`** | 백엔드 | Node.js 순수 내장 모듈 기반 REST API 서버 및 정적 웹서버 (외부 설치 불필요) |
| **`index.html`** | 프론트엔드 | 반응형 UI 마크업, 수정 모달 및 카테고리 폼 |
| **`style.css`** | 스타일 | 깔끔한 카드형 디자인, 카테고리별 테마 뱃지 및 프로그레스 바 애니메이션 |
| **`app.js`** | 프론트엔드 로직 | 백엔드 API 자동 동기화 & 오프라인 LocalStorage 백업 지원 |
| **`data/tasks.json`** | 데이터베이스 | 서버 측 작업 데이터 저장 파일 |

---

## 🚀 실행 및 종료 방법

### 1. 간편 실행 (Windows 더블 클릭)
- **실행**: 탐색기에서 **`start.bat`** 파일을 더블 클릭합니다.
  - 백엔드 서버(`server.js`)가 가동되고 자동으로 기본 브라우저(`http://localhost:3000`)가 열립니다.
- **종료**: 작업이 끝나면 **`stop.bat`** 파일을 더블 클릭합니다.
  - 3000번 포트의 서버 프로세스를 안전하게 종료합니다.

### 2. 터미널(CLI) 명령어로 실행
```bash
# 서버 시작
npm start
# 또는
node server.js

# PowerShell 스크립트로 실행
.\start.ps1

# PowerShell 스크립트로 종료
.\stop.ps1
```

### 3. 무서버(오프라인) 단독 실행
- Node.js 없이도 `index.html` 파일을 더블 클릭하면 브라우저의 `localStorage`를 통해 정상 동작합니다.

## ✨ 핵심 기능 요약
1. **카쉐어링 3대 카테고리**: `💬 채팅`, `👤 마이페이지`, `💳 결제수단` 분류 및 실시간 필터링
2. **할 일 CRUD**: 추가, 수정(모달), 삭제, 완료 체크
3. **진행률(Progress Bar)**: 달성률(%) 실시간 계산 및 100% 달성 시 축하 알림
4. **듀얼 데이터 보존**: 백엔드 REST API(`data/tasks.json`) + 브라우저 `localStorage` 자동 백업
